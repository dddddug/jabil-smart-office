## 回滚计划

### 如果部署失败：
1. 停止新服务
2. 恢复数据库备份
3. 恢复旧版本代码
4. 重新启动旧服务

### 回滚命令（Docker）：
```bash
# 停止当前服务
docker-compose down

# 使用旧版本镜像（如果有）
docker-compose pull
docker-compose up -d
```
